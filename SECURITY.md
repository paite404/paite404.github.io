# Security Policy

## Reporting Security Vulnerabilities

If you discover a security vulnerability in this portfolio website, please email **engineerstephenpaite@gmail.com** with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact

Please do not publicly disclose the vulnerability until it has been addressed.

## Security Measures

This portfolio website includes:
- **HTTPS/TLS Encryption**: All traffic is encrypted via GitHub Pages
- **Content Security Policy Headers**: Implemented to prevent XSS attacks
- **No sensitive data**: Portfolio contains only public professional information
- **Regular updates**: Dependencies and content are regularly reviewed

## Privacy

This website respects visitor privacy:
- No cookies or tracking scripts beyond GitHub's standard analytics
- No personal data collection
- All contact information is provided explicitly for professional inquiries
